## 4. 手工 E2E（macOS）

### 场景 A：发送到豆包网页

1. 打开应用时间线页（有 OCR 数据日期）。
2. 点击「发送到本地 AI 工具进行总结」并选豆包网页。
3. 验证：
   - 豆包网页打开；
   - 剪贴板内容可粘贴；
   - 若自动粘贴成功，输入框已有内容；失败则有手动粘贴提示。

### 场景 B：发送到豆包客户端

1. 点击发送并选豆包客户端。
2. 验证：
   - 客户端打开或自动回退网页；
   - 内容仍在剪贴板；
   - 用户可手动粘贴发送。

### 场景 C：一键导出

1. 点击「一键导出」。
2. 验证导出目录内存在：
   - `agent-summary.md`
   - `screenshots/*.webp`
   - `manifest.json`
