## 5. 已知限制

1. 自动粘贴受系统焦点和权限影响，当前为 best-effort，失败后会回退手动粘贴提示。
2. Windows 豆包客户端拉起默认仍以网页兜底为主。
3. 原型页在纯浏览器运行时无法直接调用 Tauri 命令，仅提供示意交互。
